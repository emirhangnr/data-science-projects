# Data Science Projects

A collection of machine learning and data analysis projects.

## Projects

### Medical Cost Prediction — Regression

Predicts individual medical insurance charges with a tuned Decision Tree. Includes EDA, interaction-based feature engineering and a Streamlit app.

[![Live App](https://img.shields.io/badge/Live%20App-ff4b4b?style=for-the-badge&logo=streamlit&logoColor=white)](https://medical-cost-regression.streamlit.app/)

### Customer Churn Prediction — Classification

Predicts telecom customer churn with a class-balanced Logistic Regression. Includes EDA, a comparison with Random Forest and Gradient Boosting, and a Streamlit app.
